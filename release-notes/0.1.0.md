**The first AltVerZ build, and an early one: expect bugs.** PvZ2 AltVerZ 1.8.3f runs natively on iPhone, iPad and Mac, with no jailbreak, no JIT and no emulator.

- The Mac build is the tested one: the title screen, the world map, the Store, the Almanac and levels work, including with a save moved over from Android.
- iPhone and iPad builds have had only light testing. Treat them as a preview.
- The game's own content, AltVerZ's War world and its levels are there.

**Known gaps**

- AltVerZ has no Import/Export screen, so moving a save over is a file copy. The README has the folders.
- The Mac app is not notarized: the first time, macOS refuses to open it until you allow it in System Settings > Privacy & Security.
- The Mac app checks this repository's update feed. Later builds will show up there; this one is the first.
- This is a prerelease. It is marked as such on GitHub and is not a stable build.
