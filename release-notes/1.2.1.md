**The game now starts with TrollStore and on older Macs.** Installed with TrollStore, the app closed as soon as it opened. On the Mac, version 1.2.0 would not open on older versions of macOS; it now runs on macOS 14 and later.

- If 1.2.0 would not open on your Mac, download this version by hand: the app can't update itself if it can't start.
- iPhone: up to 120 Hz on ProMotion models.
- `Space` now also collects sprouts.
- Import Level now refuses a file that isn't a level, and the game sets aside a bad one that was already imported, which used to crash Play.
