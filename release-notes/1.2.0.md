**Import and export your saves, and more keyboard shortcuts.** The game's own Import/Export menu (Settings, Import/Export) now works: bring your Android save over, or back it up, through the Files app on iPhone and iPad or a normal file dialog on the Mac.

- More keys: `Space` now also collects gems and plant food, `F` toggles fast-forward, `Q` picks up plant food and `Z`, `X`, `C` pick a power-up. On the Mac you can change them in Settings.
- iPhone and iPad show the game's own reminders as notifications; the game asks for permission when it first starts, as on Android. The Mac shows none.
- iPad: in a window next to other apps, a swipe that ends outside the game no longer leaves every tap dead.
- Links in the game open in your browser.
- The Mac disk image opens to a new install window, styled like the game.
- Small fixes so the game sees the same device details as on Android, and keeps its own data between launches.
